# diska — платформа продажи сайтов

Лендинг с тарифами и отзывами, регистрация клиентов, ИИ-помощник с расчётом
стоимости, личный кабинет с чатом и отдельная админ-панель с заказами.
Монохромный минималистичный дизайн, тёмная и светлая темы.

## Запуск

```bash
cd diska
npm install
npm start
```

Сайт откроется на `http://localhost:3000`

Демо-клиентов в базе нет — статистика на старте нулевая и наполняется только
реальными регистрациями, заказами и одобренными отзывами.

## Модерация отзывов

1. Клиент может оставить отзыв только по **завершённому** заказу и только один раз.
2. Новый отзыв создаётся со статусом «На модерации» и **не виден на витрине**.
3. В админ-панели (вкладка «Отзывы») вы можете:
   - **Одобрить на витрину** — отзыв появится на главной и попадёт в статистику;
   - **Скрыть с витрины** — отзыв пропадёт с главной, но останется в базе;
   - **Удалить** — отзыв удаляется полностью.
4. У клиента в кабинете его отзыв виден всегда, с пометкой «на модерации», пока не одобрен.

## Что умеет

### Публичная часть (`/`)
- Hero с сеткой и мокапом браузера, бегущая строка, CTA-блок
- Реальная статистика: клиенты, сданные проекты, отзывы, средний рейтинг
- 3 тарифа, этапы работы, блок отзывов (пустой до первой модерации)
- Переключатель тёмной/светлой темы (запоминается в браузере)
- Регистрация и вход (JWT-подобные токены, пароли — scrypt-хеши)
- Все иконки — монохромные inline-SVG, без эмодзи

### ИИ-помощник (плавающая кнопка справа внизу)
Расширенный диалог из 10 шагов: тип сайта → тематика/ниша (текстом) →
продукция и услуги (текстом) → число страниц → дизайн → фон и цветовая
тема → анимации → функции (мультивыбор) → срочность → бюджет.
Считает диапазон цены и примерный срок, оформляет заказ. На шаге бюджета
клиент не может указать сумму ниже рассчитанного минимума. Без регистрации
предложит создать аккаунт и продолжит с того же места.

### Промт для ИИ и выдача сайта
- Каждый заказ содержит готовый **промт** (кнопка «Копировать» в админке) —
  структурированное ТЗ по всем ответам клиента, его можно вставить в ИИ-генератор.
- Админ прикрепляет готовый **ZIP с сайтом** прямо к заказу — клиент скачивает
  его кнопкой «Скачать готовый сайт (ZIP)» в кабинете.

### Обмен файлами
- В чате по заказу можно отправлять **файлы любого типа до 25 МБ** с обеих
  сторон: фото, референсы, макеты, архивы, ТЗ. Картинки показываются
  превью, остальное — карточкой с названием и размером.

### Кабинет клиента (`/dashboard.html`)
- Заказы: новый / в работе / отклонён / завершён
- Итоговая цена, старт, дедлайн, комментарии и причины отказа
- Чат по каждому заказу с вложениями (автообновление каждые 4 сек)
- Скачивание готового ZIP с сайтом
- Отзыв на завершённый заказ — уходит на модерацию
- Полная адаптация под телефоны

### Админ-панель (`/admin.html`)
- Сводка: клиенты, новые заказы, заказы в работе, сданные проекты
- Промт заказа одним кликом + параметры и бюджет клиента
- Принять заказ: цена, дата старта, дедлайн, комментарий клиенту
- Отклонить с причиной / завершить проект
- Загрузка, замена и удаление ZIP с готовым сайтом
- Чат с клиентом с вложениями любого типа
- Список клиентов с числом заказов
- Модерация отзывов: одобрить / скрыть / удалить

## Как дать ссылку реальным людям

Ссылка `http://localhost:3000` работает только на том компьютере, где запущен
сервер. Публичную ссылку для клиентов даёт хостинг.

**Пошаговый гайд по бесплатному деплою на Render (с картинками действий,
без команд Git): смотрите файл [`DEPLOY-RENDER.md`](./DEPLOY-RENDER.md).**

Кратко: проект уже содержит готовый `render.yaml` — Render сам подхватит
настройки (`npm install` / `node server.js`, план Free). Нужно лишь залить
файлы на GitHub и подключить репозиторий на dashboard.render.com.

Важно: на бесплатном тарифе сервис «засыпает» после 15 минут без посетителей
(лечится бесплатным UptimeRobot — инструкция в гайде), а файловая база
`data/db.json` может сбрасываться при передеплое. Для постоянной работы с
реальными заказами стоит подключить бесплатную MongoDB Atlas — скажите,
и я переведу проект на неё.

Альтернативы для быстрого показа с личного ПК: туннели `ngrok http 3000`
или `npx localtunnel --port 3000`.

## API (кратко)

- `POST /api/register`, `POST /api/login`, `GET /api/me`
- `GET /api/stats`, `GET /api/reviews` (только одобренные), `GET /api/my-reviews`
- `POST /api/reviews` (создаётся с `approved: false`)
- `POST /api/assistant/estimate`
- `POST /api/orders`, `GET /api/orders`, `GET /api/orders/:id`, `PATCH /api/orders/:id`
- `GET/POST /api/orders/:id/messages`
- `GET /api/admin/clients`, `GET /api/admin/reviews`
- `PATCH /api/admin/reviews/:id` (`{approved: true|false}`), `DELETE /api/admin/reviews/:id`
